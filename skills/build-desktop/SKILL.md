# build-desktop

## Trigger
For Qt, Tauri, Electron, Win32, macOS and Linux desktops.

## Procedure
1. Map OS targets, permissions, windows, graphics and lifecycle interactions.
2. Estimate memory, CPU and UI responsiveness constraints.
3. Implement platform-specific fallbacks and tests.
4. Verify installers/update behavior and data preservation.
5. Report target platforms not exercised.

## Delegation policy
Use desktop-engineer with cpp-engineer, dotnet-engineer or swift-engineer as needed.

## Done when
Desktop changes with resource and packaging verification.
