# data-pipeline

## Trigger
For batch/stream data movement, Airflow, Spark, dbt or Kafka.

## Procedure
1. Define source contracts, schemas, partitions, event-time and quality checks.
2. Design idempotent backfills, retry and checkpoint strategy.
3. Validate migrations and access/privacy boundaries.
4. Test late/duplicate data and failure recovery on fixtures.
5. Document monitoring, lineage and data ownership.

## Delegation policy
Use data-engineer and database-engineer, with privacy-engineer for personal data.

## Done when
Reproducible pipeline with data-quality and recovery evidence.
