# gameplay-iteration

## Trigger
For Unity, Unreal, Godot and real-time simulation.

## Procedure
1. Describe gameplay loop and measurable fun/UX goals.
2. Inspect engine version, asset pipeline and save compatibility.
3. Implement state updates and tests without breaking persistent data.
4. Measure frame-time and loading where possible.
5. Test representative controller, accessibility and multiplayer edge cases.

## Delegation policy
Use game-engineer and qa-automation.

## Done when
Replayable gameplay result, performance notes and tested behaviors.
