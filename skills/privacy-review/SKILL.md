# privacy-review

## Trigger
When product processes user data or privacy-sensitive telemetry.

## Procedure
1. Locate collected data and processing purposes.
2. Trace access/retention/deletion and external transfers.
3. Check least privilege, logging redaction and backup behavior.
4. Propose enforceable technical controls and tests.
5. Flag any legal interpretation requiring qualified review.

## Delegation policy
Use privacy-engineer with security-auditor.

## Done when
Data-flow map, mitigations and verification checklist.
