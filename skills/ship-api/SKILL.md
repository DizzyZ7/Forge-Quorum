# ship-api

## Trigger
For FastAPI, REST, webhooks and service-to-service contracts.

## Procedure
1. Describe resources, schemas and error semantics with examples.
2. Specify authentication/authorization, timeouts, idempotency and throttling.
3. Implement input validation, logging redaction and bounded retries.
4. Update OpenAPI/docs and backward-compatibility notes.
5. Add contract, negative and integration tests.
6. Review migration implications and verify all tests that were actually run.

## Delegation policy
Use api-designer for contracts and python-backend or integration-engineer for implementation.

## Done when
Versionable contract, robust implementation, tests and documentation.
