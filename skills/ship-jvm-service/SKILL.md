# ship-jvm-service

## Trigger
For Spring, Ktor and JVM business services.

## Procedure
1. Inspect Java/Kotlin versions, build scripts, dependency locks and existing patterns.
2. Review API schemas, auth, transactions, concurrency and migrations.
3. Implement with minimal dependencies and consistent error handling.
4. Run build and targeted tests; document unavailable infrastructure.
5. Verify container/runtime settings and backward compatibility.

## Delegation policy
Use java-engineer or kotlin-engineer; add database-engineer when data changes.

## Done when
Buildable service changes and relevant tested contracts.
