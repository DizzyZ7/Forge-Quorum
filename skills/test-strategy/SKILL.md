# test-strategy

## Trigger
For test planning, flaky suites and quality gates in any stack.

## Procedure
1. Inventory existing coverage and stack-native runners.
2. Rank regression risks, integration boundaries and negative cases.
3. Add deterministic high-value tests before broad test volume.
4. Run available test targets and record exact commands/results.
5. Propose CI gates without inventing coverage numbers.

## Delegation policy
Use qa-automation and test-engineer with the implementation specialist.

## Done when
Risk-based test plan with observed evidence.
